# Civic Design Systems Cost Savings Estimator

This repository contains a lightweight Python tool designed to estimate the cost avoidance and Return on Investment (ROI) generated by major public sector open-source design systems. It compares the **U.S. Web Design System (USWDS)** against international peers like **GOV.UK** and state-level systems like the **New York State Design System (NYSDS)**.

## 📊 Methodology: How We Calculate Value

We use a straightforward, industry-standard approach to calculate the total cost savings generated by an open-source design system ecosystem. The calculation relies on three primary variables:

### 1. Base Reproduction Cost
This is the estimated cost to build the design system from scratch. We use `scc` (sloc cloc and code) to generate a COCOMO-based cost estimate of the core repository.
* **What is excluded:** We actively exclude third-party libraries and vendor output (like `node_modules` or `dist/`) so we are only valuing original code.
* **What is included:** We *fully factor in* the robust automated integration and End-to-End (E2E) testing suites that guarantee the system's security, accessibility, and production readiness.

### 2. Total Ecosystem Reach (Reuses)
We determine how many times the system has been adopted by combining:
* **GitHub Forks:** The number of times developers have copied the repository to build upon it.
* **NPM Dependents:** The number of downstream software packages that explicitly list the design system as a required dependency.

### 3. The "Discount Factor" (Reuse Percentage)
Not every project utilizes 100% of a design system. To provide realistic and defensible estimates, we apply a "Discount Factor" to the base reproduction cost per dependent. We calculate three scenarios:
* **Low (10% Reuse):** A highly conservative estimate. A 10% reuse factor means that if a team had to rewrite 90% of the code themselves, they could only reuse 10% of the original design system library.
* **Medium (50% Reuse):** A moderate estimate assuming the downstream project avoided half the cost of building a custom UI by reusing the design system.
* **High (80% Reuse):** Assumes the downstream project heavily adopted the framework, avoiding almost all the effort of building a custom system.

### 🧮 The Formula
`Total Ecosystem Savings = (Reproduction Cost) × (Total Reuses) × (Discount Factor)`
